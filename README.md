# Hangman Game 🕹️

A simple command-line Hangman game in Python, using modular files for words and ASCII art.

## Features
- Random word selection from a list
- Visual hangman stages
- Input validation for repeated guesses
- Win/Lose conditions
- Easy to extend and customize

## Files
- `main.py`: Core game logic
- `hangman_words.py`: Contains the word list
- `hangman_art.py`: Contains the logo and hangman stages

## How to Play
1. Run `main.py`
2. Guess letters one at a time
3. You have 6 lives — good luck!
